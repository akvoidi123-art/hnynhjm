# AreaMiner (клиентский мод, Fabric 26.1.2)

Выделяете область деревянной мотыгой — персонаж сам ходит и копает блоки в этой области,
подбирая выпавшие предметы. Работает только на клиенте: на сервере ничего ставить не нужно
(мод просто двигает персонажа, поворачивает камеру и удерживает кнопку атаки, как игрок).

## Как пользоваться

1. Возьмите в руку **деревянную мотыгу** (палочка выделения).
   - **ЛКМ** по блоку — точка 1
   - **ПКМ** по блоку — точка 2
   Внизу экрана покажется размер области. Блоки при этом не ломаются и земля не вскапывается.
2. Встаньте **на поверхность у верхней границы области** (на блок сверху угла области).
3. Запустите: команда `/areaminer start` или кнопка
   (**Настройки → Управление → Клавиши → AreaMiner → Старт/стоп автокопания**, по умолчанию не назначена).
4. Остановить: `/areaminer stop` или та же кнопка.

Когда в инвентаре **не остаётся свободных слотов**, внизу экрана появляется надпись
«Место в инвентаре закончилось!», копание ставится на паузу и продолжится само, как только вы
освободите место (например, выложите блоки в сундук).

## Команды

- `/areaminer start` / `/areaminer stop`
- `/areaminer status` — текущие точки и состояние
- `/areaminer clear` — сбросить выделение
- `/areaminer wand` — сделать палочкой выделения предмет, который сейчас у вас в руке

## Как копает

Область копается сверху вниз слоями, «змейкой»: персонаж выкапывает клетку перед собой, заходит в неё,
и так до конца слоя; затем выкапывает блок под ногами, спускается и идёт обратно. Из хотбара
автоматически выбирается самый быстрый инструмент для каждого блока.

## Ограничения (это простой мод, не Baritone)

- Область должна начинаться **с поверхности**: над верхней границей не должно быть блоков,
  мешающих пройти. Если персонаж не может пройти — он остановится и напишет причину.
- Останавливается сам, если: рядом лава, здоровье упало ниже 4 сердец, под клеткой пустота/жидкость
  (пещера), персонаж застрял дольше 30 секунд на одной клетке, слишком большая область (> 10 000 клеток по площади).
- Сверхтвёрдые блоки (обсидиан) без подходящей кирки могут вызвать остановку «застрял».
- Многие мультиплеерные серверы **запрещают автоматизацию** (авто-копатели). Используйте мод в одиночной
  игре или там, где это разрешено правилами сервера.

## Сборка

```bash
./gradlew build
```
Готовый jar — `build/libs/areaminer-1.0.0.jar`. Либо загрузите проект в GitHub: сборка запустится
через Actions (`.github/workflows/build.yml`), jar будет в Artifacts.

Установка: jar + **Fabric API** для 26.1.2 в папку `mods` клиента.
